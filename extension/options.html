LinguaMap extension

Sends pages, sentences and words to your LinguaMap app.

The extension needs permission for this one address so it can hand text to the page. It asks for nothing else beyond the page you right-click on, at the moment you right-click it.

No API keys here. Every translation, explanation and conversation runs on the provider configured inside LinguaMap, with the keys stored there. This extension never sees them and never calls a model itself.

Self-hosting or running locally? Point this at your own address — for example http://localhost:4173/.
